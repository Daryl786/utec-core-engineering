# Python - Functions and Modules

Ejercicios de funciones y modulos en Python 3.8 (Ubuntu 20.04).

## Archivos

- `islower.py`: devuelve True si un caracter es una letra minuscula (usa `ord()`).
- `uppercase.py`: imprime una cadena en mayusculas (usa `ord()` y `chr()`).
- `print_last_digit.py`: imprime y devuelve el ultimo digito de un numero.
- `pow.py`: calcula a elevado a b con un bucle, sin `**`.
- `simple_add.py` y `test_import.py`: comportamiento de importacion y `if __name__ == "__main__"`.
- `add.py`: importa `add` desde `add_0.py` e imprime `1 + 2 = 3`.
