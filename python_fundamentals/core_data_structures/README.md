# Python - Core Data Structures

Ejercicios de listas, tuplas, conjuntos y diccionarios en Python 3.8 (Ubuntu 20.04).

## Archivos

- `print_list_integer.py`: imprime los enteros de una lista, uno por linea.
- `element_at.py`: devuelve el elemento de una lista en un indice, o None si es negativo o esta fuera de rango.
- `replace_in_list.py`: reemplaza el elemento de una lista en un indice valido y devuelve la lista.
